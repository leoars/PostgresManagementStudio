# Contributor instructions / Instruções para agentes

- Read README.md and docs/en/development.md (or the pt-BR counterpart) before changes.
- Keep public English and Brazilian Portuguese guides synchronized.
- Preserve existing work; use only synthetic data and the isolated project test cluster.
- Never commit secrets, profiles, dumps, private operational history or local artifacts.
- Explain changes, validation actually run and known limits in pull requests.
- Codex-created commit messages must start with `[Codex]`.
- Do not publish releases or push unrelated work without authorization.
