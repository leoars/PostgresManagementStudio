# Política de fonte pública

[English](../en/public-readiness.md) | Português (Brasil)

Este repositório é uma importação selecionada de fonte com histórico Git novo. Inclui código próprio, testes sintéticos, scripts selecionados de build/pacote reproduzíveis, licença Apache-2.0, avisos de dependências e guias públicos bilíngues. Conversas de desenvolvimento, memória/backlog operacional, arquivos de marcos, anotações de máquinas/laboratório e artefatos brutos de aceitação privados não são publicados aqui.

Use o endereço noreply do GitHub nos commits quando não quiser publicar e-mail pessoal. Limite capturas a dados sintéticos. Não adicione perfis salvos, dumps, tokens, chaves privadas, payloads de recuperação criptografados, configuração específica de máquina ou artefatos de build/teste. `.gitignore` é conveniência, não substitui revisar o conteúdo preparado para commit.

A importação é revisada com Gitleaks sem exceções históricas. Varredura por padrões não comprova ausência de todo segredo possível. Revise mudanças futuras antes de publicar. Disponibilizar fonte não publica ou certifica release binária. Veja [validação](validation.md), [licenças](licensing.md) e a [política de segurança](../../SECURITY.pt-BR.md).
